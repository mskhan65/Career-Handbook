# Career Handbook

> Build skills. Ship projects. Create evidence. Build a career.

A personal career development system for becoming an **AI-Native Creative Solutions Builder**.

This repository is not a textbook and not a collection of random notes.

It is a living record of:

- What I am learning
- What I am building
- What I have shipped
- What real clients I have worked with
- What I have learned from failures and successes
- How my skills are developing
- What evidence I can show employers, clients, and partners
- Where my career is going next

# Learning Philosophy

## LEARN → BUILD → SHARE → REPEAT

The practical development workflow is:

**Understand → Use AI → Inspect → Debug → Test → Improve → Ship**

AI is treated as a force multiplier, not a replacement for understanding.
