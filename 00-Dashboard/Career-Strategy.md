# Career Strategy

## Career Identity

Target identity:

**AI-Native Creative Solutions Builder**

Not simply:

- Framer Developer
- WordPress Developer
- Frontend Developer
- AI Engineer

Those are capabilities within the larger profile.

---

# Competitive Advantage

My target advantage is the combination of:

**Design + Development + AI + Automation + Business Understanding**

A strong candidate should not only know technologies.

They should be able to understand a problem and turn it into a useful solution.

# Decision Framework

When considering a new technology, course, or opportunity, evaluate:

1. Career value
2. Business value
3. Freelance value
4. Remote-job value
5. Long-term technical value
6. Opportunity cost
7. Fit with the current phase

Do not learn something simply because it is popular.

---

# Main Career Principle

**Depth before accumulation.**

Learn enough to become useful.

Build.

Use it in real situations.

Then deepen the skill when the work demands it.

---

# Risk Management

The career should remain flexible.

Possible future directions include:

- Freelancing
- Remote employment
- Agency work
- Partnerships
- Product development
- AI solutions
- Entrepreneurship

The roadmap should increase optionality rather than lock me into one technology.
