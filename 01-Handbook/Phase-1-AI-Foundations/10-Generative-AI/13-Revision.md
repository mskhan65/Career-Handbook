# 📘 Chapter 02 — What is Generative AI?

## Key Points

Generative AI can create:

- Text
- Images
- Audio
- Video

# 📘 Chapter 04 — Foundation Models

Foundation Models are large pre-trained models that can be adapted for many tasks.

Examples:

- Text generation
- Translation
- Summarization
- Coding
- Question answering

Benefits:

- Reusable
- Scalable
- Flexible

# 📘 Chapter 05 — Large Language Models (LLMs)

LLMs:

- Learn language patterns
- Predict the next token
- Generate text
- Answer questions
- Summarize documents
- Write software code

Workflow

```text
Prompt

↓

Tokenizer

↓

LLM

↓

Next Token Prediction

↓

Response
```

# 📘 Chapter 06 — Diffusion Models

Diffusion Models generate images by removing noise.

Training

```text
Image

↓

Add Noise

↓

Random Noise
```

Generation

```text
Random Noise

↓

Remove Noise

↓

Generated Image
```

Applications

- AI Art
- Product Design
- Image Editing
- Photo Restoration

---

# 📘 Chapter 07 — GANs

GANs consist of two neural networks.

```text
Generator

↓

Creates Image

↓

Discriminator

↓

Real?

Fake?

↓

Feedback

↓

Generator Improves
```

Applications

- Face generation
- Super-resolution
- Image synthesis
- Style transfer

# 📊 Traditional AI vs Generative AI

| Traditional AI | Generative AI |
|----------------|---------------|
| Predicts | Creates |
| Classification | Content Generation |
| Analysis | Creativity |
| Decision Making | Text, Images, Code, Audio |

---

# 📊 Foundation Model vs LLM

| Foundation Model | LLM |
|------------------|-----|
| Broad-purpose pretrained model | Specialized Foundation Model for language |
| Can support multiple domains | Primarily processes language |
| Adaptable to many tasks | Generates text and code |

---

# 📊 LLM vs Diffusion Model

| LLM | Diffusion Model |
|-----|-----------------|
| Generates text | Generates images |
| Predicts next token | Removes noise step by step |
| Transformer-based | Denoising process |

---

# 📊 GAN vs Diffusion Model

| GAN | Diffusion |
|-----|-----------|
| Generator + Discriminator | Noise removal |
| Faster generation | Higher-quality images in many applications |
| More difficult training | Generally more stable training |

---

# 📊 Single-Modal vs Multimodal AI

| Single-Modal | Multimodal |
|--------------|------------|
| One data type | Multiple data types |
| Limited context | Rich understanding |
| Text OR Image | Text + Image + Audio + Video + More |
