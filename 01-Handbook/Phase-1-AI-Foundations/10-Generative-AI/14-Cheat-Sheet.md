# 🧠 What is Generative AI?

> **Generative AI is a branch of Artificial Intelligence that learns patterns from existing data to create new content such as text, images, audio, video, code, and more.**

---

# ⚡ Traditional AI vs Generative AI

| Traditional AI | Generative AI |
|----------------|---------------|
| Analyzes existing data | Creates new content |
| Classification | Generation |
| Prediction | Creativity |
| Detects patterns | Produces text, images, code, etc. |
| Spam Detection | ChatGPT, DALL·E |

# 🏛️ Foundation Models

## Definition

Large pre-trained AI models that can be adapted for many different tasks.

Examples:

- Text generation
- Translation
- Coding
- Summarization
- Question answering
- Image generation

---

# 🤖 Large Language Models (LLMs)

## Definition

A Large Language Model (LLM) is a Foundation Model trained primarily on text that generates language by predicting the next token.

Workflow

```text
Prompt

↓

Tokenizer

↓

LLM

↓

Next Token Prediction

↓

Response
```

Common Uses

- Chatbots
- Coding
- Translation
- Writing
- Summarization
- Question Answering

---

# 🎨 Diffusion Models

## Definition

Generate images by gradually removing noise from random data.

Training

```text
Image

↓

Add Noise

↓

Random Noise
```

Generation

```text
Random Noise

↓

Remove Noise

↓

Generated Image
```

Applications

- AI Art
- Photo Restoration
- Image Editing
- Product Design

---

# 📌 Key AI Terms

| Term | Meaning |
|------|---------|
| Prompt | Instruction given to AI |
| Token | Small unit of text processed by an LLM |
| Embedding | Numerical representation of data |
| Inference | Using a trained model to generate output |
| Hallucination | AI-generated incorrect information |
| Foundation Model | Large reusable pretrained model |
| LLM | Language-focused Foundation Model |
| Diffusion Model | Generates images through denoising |
| GAN | Generator + Discriminator architecture |
| Multimodal AI | AI that understands multiple data types |

---

# 📊 LLM vs Diffusion Model

| LLM | Diffusion Model |
|-----|-----------------|
| Text generation | Image generation |
| Next-token prediction | Reverse diffusion |
| Transformer | Denoising process |
| Language | Computer Vision |

---

# 📊 GAN vs Diffusion Model

| GAN | Diffusion |
|-----|-----------|
| Two neural networks | One denoising model |
| Faster generation | Higher image quality in many tasks |
| Difficult training | More stable training |
| Generator + Discriminator | Reverse diffusion |

---

# 📊 Foundation Model vs LLM

| Foundation Model | LLM |
|------------------|-----|
| General-purpose pretrained model | Language-focused Foundation Model |
| Many downstream tasks | Language generation |
| Broader scope | Text specialization |

---

# 📊 Single-Modal vs Multimodal AI

| Single Modal | Multimodal |
|--------------|------------|
| Text only | Text + Image |
| Image only | Text + Audio |
| One input type | Multiple input types |
| Limited context | Rich context |
