# 📄 Machine Learning Cheat Sheet

> **Quick revision notes for Machine Learning fundamentals.**

---

# 🤖 What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn from data and make predictions or decisions without being explicitly programmed.

---


# 🎯 Why Machine Learning?

Machine Learning is used when:

- Rules are difficult to write.
- Large amounts of data are available.
- Predictions are required.
- Hidden patterns exist in data.
- Systems need to improve over time.

# 🏷️ Features and Labels

## Features

- Input variables
- Describe the object
- Used for prediction

Examples:

- Age
- Salary
- House Size
- Experience

---

## Labels

- Correct output
- Target variable
- Value to predict

Examples:

- House Price
- Spam / Not Spam
- Loan Approved
- Pass / Fail

---

# 🏋️ Training vs Testing

```text
Dataset
   │
   ├──────────────┐
   ▼              ▼

Training       Testing

Learn         Evaluate
```

## Training Data

- Used to teach the model
- Learns patterns
- Contains features and labels

---

## Testing Data

- Used after training
- Unseen data
- Evaluates performance

---

# 📊 Common Dataset Split

| Training | Testing |
|-----------|----------|
| 70% | 30% |
| 80% | 20% |
| 90% | 10% |

Most common:
