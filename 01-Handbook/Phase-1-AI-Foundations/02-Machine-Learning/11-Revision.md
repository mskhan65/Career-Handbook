---

# 🎯 Machine Learning Definition

> **Machine Learning is a branch of Artificial Intelligence that enables computers to learn from data and improve their performance without being explicitly programmed for every task.**

---

# 🤖 Why Machine Learning?

Traditional programming struggles with complex problems.

Machine Learning is useful when:

- Rules are difficult to define.
- Large amounts of data are available.
- Predictions are needed.
- Patterns are hidden in data.
- Systems should improve over time.

# 🏷️ Features and Labels

```text
Features
(Input)

Age
Salary

        │
        ▼

Machine Learning Model

        │
        ▼

Label
(Output)

House Price
Loan Approved

```

## Features

- Input variables
- Describe an object
- Used for prediction

Examples:

- Age
- Salary
- Experience
- House Size

---

## Labels

- Correct output
- Target value
- Answer the model learns

Examples:

- House Price
- Spam / Not Spam
- Loan Approved
- Pass / Fail

---

# 🏋️ Training vs Testing

```text
Dataset
   │
   ├──────────────┐
   ▼              ▼

Training       Testing

Learn         Evaluate
```

## Training Data

- Used to teach the model.
- Contains features and labels.
- Helps the model learn patterns.

---

## Testing Data

- Used after training.
- Contains unseen data.
- Measures model performance.

# ✅ Advantages

Machine Learning:

- Learns from data
- Automates repetitive tasks
- Handles large datasets
- Makes predictions
- Improves over time
- Supports better decision-making

---

# ⚠️ Limitations

Machine Learning:

- Requires quality data
- Needs computational resources
- Can be difficult to interpret
- Is not always 100% accurate
- Requires continuous monitoring

---

# 📊 Traditional Programming vs Machine Learning

| Traditional Programming | Machine Learning |
|--------------------------|------------------|
| Programmer writes rules | Computer learns rules |
| Best for simple problems | Best for complex problems |
| Fixed behavior | Improves with more data |
| Limited adaptability | Learns patterns automatically |
