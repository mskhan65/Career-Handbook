# 📖 Machine Learning Dictionary

> *A glossary of important Machine Learning terms covered in this chapter.*

---

# A

## Accuracy

A performance metric that measures how many predictions made by a Machine Learning model are correct.

**Example:**

If a model correctly predicts 95 out of 100 cases, its accuracy is **95%**.

---

## Algorithm

A mathematical method or set of rules that enables a computer to learn patterns from data.

**Examples:**

- Linear Regression
- Decision Tree
- Random Forest
- Neural Network

---

## Artificial Intelligence (AI)

The broad field of computer science focused on building systems that can perform tasks requiring human intelligence.

Machine Learning is a subset of Artificial Intelligence.

---

# B

## Black Box Model

A Machine Learning model whose internal decision-making process is difficult to understand.

Deep Learning models are common examples of black box models.

---

## Business Problem

The real-world problem that a Machine Learning project aims to solve.

**Examples:**

- Predict customer churn
- Detect fraud
- Forecast sales

---

# C

## Computational Resources

The hardware and computing power required to train and run Machine Learning models.

Examples include:

- CPU
- GPU
- Memory (RAM)
- Cloud Servers

---

## Customer Churn

The percentage of customers who stop using a product or service.

Machine Learning models can predict which customers are likely to leave.

---

# D

## Data

A collection of facts, measurements, or observations used by Machine Learning models for learning.

Examples:

- Images
- Numbers
- Text
- Videos
- Audio

---

## Data Collection

The process of gathering data from various sources before building a Machine Learning model.

---

## Data Preparation

The process of cleaning, organizing, and transforming raw data before training a model.

Common tasks include:

- Removing duplicates
- Handling missing values
- Correcting errors

---

## Dataset

A structured collection of data used for training and testing Machine Learning models.

---

## Deployment

The process of making a trained Machine Learning model available for real-world use.

---

# E

## Evaluation

The process of measuring how well a Machine Learning model performs using unseen data.

---

# F

## Feature

An input variable used by a Machine Learning model to make predictions.

**Examples:**

- Age
- Salary
- House Size
- Experience

---

## Feature Engineering

The process of selecting, creating, or transforming features to improve model performance.

---

## Fraud Detection

Using Machine Learning to identify suspicious or fraudulent activities.

Commonly used in banking and finance.

---

# G

## Generalization

The ability of a Machine Learning model to perform well on new, unseen data instead of memorizing the training data.

---

## Garbage In, Garbage Out (GIGO)

A principle stating that poor-quality input data leads to poor-quality predictions.

---

# I

## Input Variable

Another name for a **Feature**.

---

# L

## Label

The correct output or answer that the model learns to predict.

**Examples:**

- House Price
- Loan Approved
- Spam
- Pass/Fail

---

## Learning Algorithm

The algorithm responsible for finding patterns in data during training.

---

# M

## Machine Learning (ML)

A branch of Artificial Intelligence that enables computers to learn from data without being explicitly programmed for every task.

---

## Model

The trained system produced after learning patterns from data.

The model is used to make predictions on new data.

---

## Monitoring

The process of continuously checking a deployed Machine Learning model to ensure it maintains good performance.

---

# O

## Output Variable

Another name for a **Label**.

---

# P

## Pattern

A relationship or trend discovered in data during training.

---

## Prediction

The output generated by a trained Machine Learning model for new data.

---

## Predictor

Another name for a **Feature**.

---

# R

## Recommendation System

A Machine Learning system that suggests products, movies, songs, or other content based on user behavior.

Examples:

- Netflix
- Amazon
- Spotify

---

## Retraining

Training an existing Machine Learning model again using updated data to improve performance.

---

# T

## Target Variable

Another name for a **Label**.

---

## Testing Data

The portion of the dataset used to evaluate a trained Machine Learning model.

Testing data is not used during training.

---

## Traditional Programming

A programming approach where developers manually write rules for the computer to follow.

---

## Training

The process of teaching a Machine Learning model using historical data.

---

## Training Data

The portion of the dataset used to teach a Machine Learning model.

---

# W

## Workflow

The sequence of steps followed to build a Machine Learning model.

Typical workflow:

```text
Collect Data
      ↓
Prepare Data
      ↓
Choose Algorithm
      ↓
Train Model
      ↓
Evaluate Model
      ↓
Make Predictions
```
