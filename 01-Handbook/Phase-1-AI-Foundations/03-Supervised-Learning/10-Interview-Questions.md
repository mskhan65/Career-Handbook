# 🟢 Beginner Level Questions

## 1. What is Supervised Learning?

### Sample Answer

Supervised Learning is a type of Machine Learning where a model is trained using labeled data. Each training example contains input features and the correct output label. The model learns the relationship between them and uses this knowledge to predict outputs for new, unseen data.

---

## 2. Why is it called Supervised Learning?

### Sample Answer

It is called Supervised Learning because the model learns from labeled examples where the correct answers are already known. These labels act like a teacher guiding the learning process.

---

## 3. What is labeled data?

### Sample Answer

Labeled data is a dataset where every input has a corresponding correct output. The inputs are called features, and the correct outputs are called labels.

---

## 4. What are features and labels?

### Sample Answer

Features are the input variables used by the model to make predictions, while labels are the correct outputs that the model learns to predict.

---

## 5. Give some real-world applications of Supervised Learning.

### Sample Answer

Supervised Learning is used in:

- Spam email detection
- Fraud detection
- House price prediction
- Disease diagnosis
- Loan approval
- Sales forecasting
- Face recognition
- Customer churn prediction

---

# 🟡 Intermediate Level Questions

## 6. What are the two main types of Supervised Learning?

### Sample Answer

The two main types are:

- **Regression**, which predicts continuous numerical values.
- **Classification**, which predicts predefined categories or classes.

---

## 7. What is the difference between Regression and Classification?

### Sample Answer

Regression predicts continuous numerical values such as house prices or salaries.

Classification predicts categories such as spam or not spam, fraud or not fraud, and pass or fail.

---

## 8. Explain how Supervised Learning works.

### Sample Answer

The process begins with collecting labeled data. The data is cleaned and prepared, then used to train a Machine Learning algorithm. The trained model is evaluated using unseen data, and once it performs well, it is used to make predictions on new data.

---

## 9. Why is labeled data important?

### Sample Answer

Labeled data provides the correct answers during training. Without labels, the model cannot learn the relationship between the inputs and outputs.

---

## 10. What are some common Supervised Learning algorithms?

### Sample Answer

Common algorithms include:

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naïve Bayes

---

# 🔵 Advanced Level Questions

## 11. What are the advantages of Supervised Learning?

### Sample Answer

Some advantages include:

- High prediction accuracy
- Easy performance evaluation
- Supports Regression and Classification
- Widely used in industry
- Learns from historical data
- Automates decision-making

---

## 12. What are the limitations of Supervised Learning?

### Sample Answer

Some limitations include:

- Requires labeled data
- Data labeling can be expensive
- Sensitive to poor-quality data
- Risk of overfitting
- Requires periodic retraining
- Can require significant computational resources

---

## 13. What is overfitting?

### Sample Answer

Overfitting occurs when a model learns the training data too closely, including noise and unnecessary details. As a result, it performs well on training data but poorly on new, unseen data.

---

## 14. How do you choose the right algorithm?

### Sample Answer

The choice depends on:

- Whether the problem is Regression or Classification
- Dataset size
- Data complexity
- Required accuracy
- Available computing resources
- Model interpretability

In practice, multiple algorithms are often tested, and the best-performing one is selected.

---

## 15. Why should a Machine Learning model be retrained?

### Sample Answer

Real-world data changes over time. Customer behavior, market trends, and business conditions may evolve. Retraining helps the model learn these new patterns and maintain good prediction accuracy.

---

# 💼 Scenario-Based Questions

## 16. A bank wants to detect fraudulent transactions. Which type of Supervised Learning would you use?

### Sample Answer

I would use **Classification** because the output is categorical:

- Fraud
- Not Fraud

Algorithms such as Random Forest, Logistic Regression, or Decision Tree are commonly used.

---

## 17. A real estate company wants to predict house prices. Which type of Supervised Learning would you use?

### Sample Answer

I would use **Regression** because house prices are continuous numerical values.

Linear Regression, Decision Tree Regression, or Random Forest Regression are suitable choices.

---

## 18. A hospital wants to predict whether a patient has a disease. Which type of Supervised Learning would you use?

### Sample Answer

This is a **Classification** problem because the prediction is a category such as:

- Disease
- No Disease

---

## 19. An online store wants to predict next month's sales. Which type of Supervised Learning would you use?

### Sample Answer

This is a **Regression** problem because sales are represented by continuous numerical values.

---

## 20. A company wants to classify customer emails into "Support", "Sales", and "Billing". Which type of Supervised Learning would you use?

### Sample Answer

This is a **Multiclass Classification** problem because there are more than two predefined categories.
