# 🎯 Supervised Learning

**Definition**

A type of Machine Learning where a model learns from **labeled data** to predict outputs for new, unseen data.

---

# 🧠 Basic Workflow

```text
Labeled Data
      │
      ▼
Prepare Data
      │
      ▼
Choose Algorithm
      │
      ▼
Train Model
      │
      ▼
Evaluate Model
      │
      ▼
Predict New Data
```

---

# 📚 Key Terms

| Term | Meaning |
|------|---------|
| Supervised Learning | Learning from labeled data |
| Feature | Input variable |
| Label | Correct output |
| Model | Trained prediction system |
| Training | Teaching the model |
| Testing | Evaluating the model |
| Prediction | Model's output for new data |
| Algorithm | Mathematical method used for learning |

# 🔀 Types of Supervised Learning

```text
Supervised Learning
        │
 ┌──────┴──────┐
 ▼             ▼

Regression   Classification
```

---

## 📈 Regression

### Predicts

Continuous numerical values

### Examples

- House Price
- Salary
- Temperature
- Sales Forecast
- Electricity Demand

### Common Algorithms

- Linear Regression
- Polynomial Regression
- Decision Tree Regression
- Random Forest Regression
- Support Vector Regression (SVR)

---

## 🏷️ Classification

### Predicts

Categories or classes

### Examples

- Spam Detection
- Loan Approval
- Fraud Detection
- Disease Diagnosis
- Pass / Fail

### Types

- Binary Classification
- Multiclass Classification
- Multilabel Classification

### Common Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
- SVM
- KNN
- Naïve Bayes

---

# ⚖️ Regression vs Classification

| Regression | Classification |
|------------|----------------|
| Predicts numbers | Predicts categories |
| Continuous output | Discrete output |
| House price | Spam detection |
| Salary | Loan approval |
| Sales forecasting | Disease diagnosis |

---

# 🤖 Common Algorithms

| Algorithm | Regression | Classification |
|-----------|:----------:|:--------------:|
| Linear Regression | ✅ | ❌ |
| Logistic Regression | ❌ | ✅ |
| Decision Tree | ✅ | ✅ |
| Random Forest | ✅ | ✅ |
| SVM | ✅* | ✅ |
| KNN | ✅ | ✅ |
| Naïve Bayes | ❌ | ✅ |

> **Note:** SVM is mainly used for Classification. Its Regression version is called **Support Vector Regression (SVR)**.

# 🌟 Advantages

- High prediction accuracy
- Learns from historical data
- Easy to evaluate
- Supports Regression and Classification
- Automates decision-making
- Widely used across industries
- Reduces manual work

---

# ⚠️ Limitations

- Requires labeled data
- Data labeling is expensive
- Sensitive to poor-quality data
- Risk of overfitting
- Needs retraining
- High computational cost
- Limited to learned patterns
