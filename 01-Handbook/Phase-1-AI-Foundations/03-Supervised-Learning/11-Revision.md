# 🎯 Chapter Overview

Supervised Learning is a type of Machine Learning where a model learns from **labeled data**.

Each training example contains:

- **Features (Inputs)**
- **Labels (Correct Outputs)**

The model learns the relationship between them and predicts the correct output for new, unseen data.

# 📖 Key Definitions

| Concept | Definition |
|---------|------------|
| Supervised Learning | A Machine Learning approach that learns from labeled data. |
| Feature | An input variable used for prediction. |
| Label | The correct output associated with the input. |
| Training | Teaching the model using labeled examples. |
| Prediction | The output generated by the trained model. |
| Model | A trained system that makes predictions. |

---

## 📈 Regression

### Purpose

Predicts **continuous numerical values**.

### Examples

- House Price Prediction
- Salary Prediction
- Sales Forecasting
- Temperature Prediction
- Electricity Demand

### Output

```text
$320,000

28°C

75,000
```

---

## 🏷️ Classification

### Purpose

Predicts **predefined categories**.

### Examples

- Spam Detection
- Fraud Detection
- Disease Diagnosis
- Loan Approval
- Pass or Fail

### Output

```text
Spam

Approved

Disease
```

---

# ⚖️ Regression vs Classification

| Regression | Classification |
|------------|----------------|
| Predicts numbers | Predicts categories |
| Continuous output | Discrete output |
| House prices | Spam detection |
| Salary | Loan approval |
| Sales forecasting | Disease diagnosis |

# 🤖 Common Algorithms

| Algorithm | Regression | Classification |
|-----------|:----------:|:--------------:|
| Linear Regression | ✅ | ❌ |
| Logistic Regression | ❌ | ✅ |
| Decision Tree | ✅ | ✅ |
| Random Forest | ✅ | ✅ |
| Support Vector Machine (SVM) | ✅* | ✅ |
| K-Nearest Neighbors (KNN) | ✅ | ✅ |
| Naïve Bayes | ❌ | ✅ |

> **Note:** SVM is mainly used for Classification. Its Regression version is called **Support Vector Regression (SVR)**.

# ✅ Advantages

- High prediction accuracy
- Learns from labeled historical data
- Easy to evaluate
- Supports Regression and Classification
- Widely used in industry
- Automates decision-making
- Reduces manual work

---

# ⚠️ Limitations

- Requires labeled data
- Data labeling can be expensive
- Sensitive to poor-quality data
- Risk of overfitting
- Needs regular retraining
- Computationally expensive for large datasets
- Limited to patterns seen during training

# 🎤 Interview Quick Review

### What is Supervised Learning?

A Machine Learning technique where a model learns from labeled data to predict outputs for new data.

---

### What is Regression?

Regression predicts continuous numerical values.

Example:

- House Price Prediction

---

### What is Classification?

Classification predicts predefined categories.

Example:

- Spam Detection

---

### Name common algorithms.

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- SVM
- KNN
- Naïve Bayes

---

### What are the advantages?

- Accurate predictions
- Learns from historical data
- Easy evaluation
- Business automation

---

### What are the limitations?

- Requires labeled data

- Overfitting
- Requires retraining
