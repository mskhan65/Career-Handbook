# 📖 Supervised Learning Dictionary

> *"This dictionary contains the most important terms related to Supervised Learning. Use it as a quick reference while studying, building Machine Learning models, or preparing for interviews."*

---

# A

## Accuracy

A performance metric that measures how many predictions made by a model are correct out of all predictions.

---

## Algorithm

A mathematical procedure or set of rules that enables a Machine Learning model to learn patterns from data and make predictions.

---

# B

## Binary Classification

A type of Classification problem where there are only two possible output classes.

**Examples**

- Spam / Not Spam
- Yes / No
- Pass / Fail
- Fraud / Not Fraud

---

# C

## Classification

A type of Supervised Learning that predicts predefined categories or classes.

**Example**

Predict whether an email is spam.

---

## Class Label

The correct category assigned to a data point.

**Examples**

- Approved
- Rejected
- Positive
- Negative

---

## Continuous Value

A numerical value that can take any value within a range.

**Examples**

- House Price
- Temperature
- Salary

---

# D

## Dataset

A collection of data used to train, validate, or test a Machine Learning model.

---

## Decision Tree

A Machine Learning algorithm that makes predictions using a tree-like structure of decisions.

Used for:

- Regression
- Classification

---

# E

## Evaluation

The process of measuring how well a trained Machine Learning model performs on unseen data.

---

## Evaluation Metric

A measurement used to assess the performance of a Machine Learning model.

Common examples include:

- Accuracy
- Precision
- Recall
- F1 Score
- MAE
- MSE

---

# F

## Feature

An input variable used by the model to make predictions.

**Example**

For house price prediction:

- House Size
- Number of Bedrooms
- Location

---

# K

## K-Nearest Neighbors (KNN)

A Supervised Learning algorithm that predicts based on the most similar training examples.

Used for:

- Classification
- Regression

---

# L

## Label

The correct output associated with a training example.

The model learns to predict labels from features.

---

## Labeled Data

Data that contains both input features and the correct output labels.

Labeled data is required for Supervised Learning.

---

## Learning Algorithm

The mathematical method used to discover patterns from labeled data.

---

## Linear Regression

A Regression algorithm that models the relationship between variables using a straight line.

Used for predicting continuous numerical values.

---

## Logistic Regression

A Classification algorithm that predicts the probability of different classes.

Despite its name, it is mainly used for Classification.

---

# M

## Machine Learning Model

A trained system that has learned patterns from data and can make predictions on new data.

---

## Mean Absolute Error (MAE)

A Regression evaluation metric that measures the average absolute difference between predicted values and actual values.

Lower MAE indicates better performance.

---

## Mean Squared Error (MSE)

A Regression evaluation metric that measures the average squared difference between predicted values and actual values.

Lower MSE indicates better performance.

---

## Model

A trained representation of learned patterns used for making predictions.

---

## Multiclass Classification

A Classification problem with more than two possible output classes.

**Examples**

- Cat
- Dog
- Bird

---

## Multilabel Classification

A Classification problem where one data point can belong to multiple categories simultaneously.

**Example**

A movie can belong to:

- Action
- Adventure
- Comedy

---

# N

## Naïve Bayes

A probability-based Classification algorithm built on Bayes' Theorem.

Commonly used for:

- Spam Detection
- Sentiment Analysis
- Document Classification

---

# O

## Overfitting

A situation where a model learns the training data too closely, including noise, resulting in poor performance on new, unseen data.

---

# P

## Pattern

A relationship discovered by the model during training.

Patterns help the model make predictions.

---

## Prediction

The output produced by a trained Machine Learning model for new data.

---

## Precision

A Classification evaluation metric that measures how many predicted positive cases are actually positive.

---

# R

## Random Forest

A Machine Learning algorithm that combines multiple Decision Trees to improve prediction accuracy.

Used for:

- Regression
- Classification

---

## Recall

A Classification evaluation metric that measures how many actual positive cases are correctly identified.

---

## Regression

A type of Supervised Learning used to predict continuous numerical values.

**Examples**

- House Price Prediction
- Salary Prediction
- Sales Forecasting

---

## Root Mean Squared Error (RMSE)

A Regression evaluation metric that measures prediction error using the square root of the Mean Squared Error.

Lower RMSE indicates better predictions.

---

# S

## Support Vector Machine (SVM)

A Supervised Learning algorithm that finds the optimal boundary between different classes.

Primarily used for Classification.

---

## Support Vector Regression (SVR)

The Regression version of Support Vector Machine used to predict continuous numerical values.

---

## Supervised Learning

A type of Machine Learning where a model learns from labeled data to predict outputs for new, unseen data.

---

# T

## Testing

The process of evaluating a trained model using unseen data to measure its performance.

---

## Training

The process of teaching a Machine Learning model using labeled data so it can learn patterns.

---

## Training Data

The portion of the dataset used to teach the model.

---

# V

## Validation

The process of checking model performance during development to help select the best model and tune its settings before final testing.

---

# W

## Workflow

The sequence of steps followed to build a Supervised Learning model.

```text
Collect Data
      │
      ▼
Prepare Data
      │
      ▼
Choose Algorithm
      │
      ▼
Train Model
      │
      ▼
Evaluate Model
      │
      ▼
Predict
```
